# Tech lead

Coordena especialistas de uma entrega e integra as partes.

Voltar a [responsabilidades](/docs/engineering/responsibilities.md) · Catálogo: [organization.py](/src/agent/domain/organization.py)

## 🎯 Missão e equipe

| Campo | Valor |
|-------|-------|
| Id | `tech_lead` |
| Equipe | Core Engineering |
| Exercido por | agente lógico do Callidus |
| Especialidades | Engenharia de software, Arquitetura de sistemas |
| Autoridade | distribuição entre especialistas; decomposição |
| Escala para | Arquiteto de software |

## 🧰 Trabalho

| Campo | Valor |
|-------|-------|
| Tarefas que assume | tarefa raiz e subsistemas |
| Artefatos | distribuição entre especialistas e integração das partes |
| Áreas de que é dono | — |
| Revisa o trabalho de | Desenvolvedor backend, Desenvolvedor frontend, Engenheiro de IA, Engenheiro de conhecimento |
| Quem revisa este papel | Arquiteto de software, CTO, Code reviewer, QA engineer |
| Escalona quando | um especialista não tem confiança para executar ou a entrega cruza áreas protegidas |

## ✅ Critérios de qualidade

As regras do [AGENTS.md](/AGENTS.md) valem para todo papel. A aprovação passa pelos [portões](/docs/engineering/quality-gates.md); ferramentas permitidas são as do catálogo e da política de aprovação ([ferramentas.md](/docs/architecture/ferramentas.md)) — o papel não amplia permissão.
